## 🚧 Troubleshooting
- **Blank page**: Ensure JavaScript is enabled your browser (chrome: Settings > Privacy > Site settings > JavaScript)
- **No images**: Ensure all files from the ZIP were extracted (don't move files from folders)
- **Calculator not working**: Update your browser to the latest version
- **Language not changing**: Clear your browser's cache and refresh the page
